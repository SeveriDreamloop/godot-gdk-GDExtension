# Godot GDK GDExtension

Work in progress GDExtension that adds Microsoft GDK functionality to Godot.

## Quick start

1. Install GDK https://github.com/microsoft/GDK#installation
2. Finish Requirements and Setting up SCons sections of Compiling Godot for Windows guide https://docs.godotengine.org/en/stable/engine_details/development/compiling/compiling_for_windows.html#requirements
3. Clone the project using `git clone --recurse-submodules https://github.com/SeveriDreamloop/godot-gdk-GDExtension.git`. This way, it will clone with all the submodules included.
4. Run `scons` command

GDExtension should build successfully and binaries will be copied to the demo project into addons folder.
